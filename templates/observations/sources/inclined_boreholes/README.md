# Наклонное бурение

Самостоятельный шаблон источника `inclined_boreholes`. Скважины наклонные: `-90 < dip_deg < 0`. В примере угол -60°, азимут 90° (на восток).

`observations.json` содержит пакет целиком и его `source_id`. Восемь CSV представляют те же записи: устья, литологию, анализы, физические свойства, структурные наблюдения, интервалы нарушений, гамма-каротаж и магнитный каротаж. Пустая таблица `fault_intersections.csv` содержит только заголовок: пример не утверждает наличие разлома.

Идентификаторы `EXAMPLE-I-*` нужно заменить. Связывайте записи по `campaign_id` и `hole_id`, анализы — дополнительно по `sample_id`. Пример журнала покрывает весь ствол; анализ и физическое измерение показаны для одного интервала, оба вида каротажа — для трёх. Поля глубины и интервалы задаются вдоль ствола.

Общий справочник формата находится в [observations.md](../../observations.md). Лабораторный контроль кампании хранится отдельно в `quality_control.csv` общего пакета.
